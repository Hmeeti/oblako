# Модель данных

См. `prisma/schema.prisma`. Кратко:

| Сущность | Назначение |
|----------|------------|
| `User` / `Session` | Пользователи кабинета, сессии |
| `ProjectMember` | Роли `project_owner` / `project_editor` на проект |
| `Lead` | Заявки с лендинга |
| `Project` | Заведение (`slug`, статус, тема, фичи) |
| `Category` / `Item` | Черновик меню; мультиязычные JSON-поля |
| `MenuVersion` | Снимок публикации; публичная страница читает последний |
| `QrCode` | Короткие коды → `/q/{code}` |
| `ScanEvent` / `MenuView` / `ItemTap` | Агрегированная аналитика без ПДн |
| `AuditLog` | Аудит цен, публикации, ролей |
| `Setting` | Настройки платформы (не секреты) |
| `LeadRateLimit` | Антиспам заявок |

## Мультитенантность

Все таблицы меню/QR/аналитики содержат `projectId`. Запросы API всегда фильтруют по нему и проверяют `can()`.

## Демо

`Project.demo = true` — данные из `seed/parkavenue`, удаляются одной командой.
