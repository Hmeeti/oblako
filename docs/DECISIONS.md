# Технические решения

## Auth: собственный session-слой (вместо better-auth / Auth.js v5)

**Решение:** сессии в таблице `Session`, пароли через `argon2id`, cookie `stolio_session` (`httpOnly`, `Secure` в prod, `SameSite=Lax`).

**Почему не better-auth в первом проходе:** конфликт peer-зависимостей с Vitest/`@types/node` на чистой установке замедлял фундамент. Пакет `better-auth` остаётся в зависимостях как кандидат на миграцию.

**Почему не Auth.js сразу:** Credentials + argon2id потребовали бы того же объёма кастомного кода; тонкий свой слой проще для изоляции тестов `can()`.

**Критерии совместимости с промптом:** email+пароль, сброс пароля (модель `PasswordResetToken` готова; UI сброса — TODO дополировать), сессии в httpOnly cookie.
